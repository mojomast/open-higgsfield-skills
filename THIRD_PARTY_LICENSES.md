# Third-party licences and provenance

This repository's own text and scripts are MIT-licensed (see `LICENSE`). It also includes files copied from other open-source projects. Each copied file keeps its original licence, and the full upstream licence texts are in [`licenses/`](licenses/) (Apache-2.0 NOTICE files are included where the upstream ships one). Bundled ComfyUI node packs also keep their own `LICENSE` inside their `assets/` folder.

**No model weights are bundled.** Workflows reference weight files that you download yourself, under each model's own licence. The weight licences below come from public knowledge of each model family and are marked **unverified** unless checked against the model card. Confirm them before any commercial use. The Lightricks LTX-2 weights are under the LTX-2 Community License, which is not an OSI-approved open-source licence; a reference copy is in `licenses/LTX-2-weights-LICENSE.reference.txt` for convenience only.

Licence audit method (2026-10-30): every copied workflow, preset, script and node-pack file was matched byte-for-byte (JSON compared after canonical re-serialisation) against the upstream repositories at the pinned commits below. Each upstream licence was checked with both the GitHub API and the repository's LICENSE file. Only MIT, Apache-2.0 and BSD (0BSD) material is included.
